# CosmicRaid - Community Management Platform

A powerful Discord and Twitch integration platform for streaming communities, featuring automated shoutouts, points systems, leaderboards, and community engagement tools.

## 🚀 Features

- **Automated Shoutouts**: AI-powered community spotlight system
- **Points & Leaderboards**: Track community engagement across Discord and Twitch
- **Event Calendar**: Community mission calendar with Discord integration
- **Raid Pile**: Coordinate community raids and support
- **Multi-Tenant**: Support for multiple Discord servers
- **Real-time Updates**: Live community metrics and status

## 🛠️ User Tools

### Discord Commands
- `/calendar` - Display community calendar and leaderboard
- `/rank` - Check your current points and ranking
- Use Discord interactions to participate in community events

### Web Interface
- **Dashboard**: Overview of community activity and stats
- **Leaderboard**: View top community contributors
- **Calendar**: Browse upcoming events and missions
- **Settings**: Configure your server preferences
- **Raid Pile**: Join community raid coordination

## 🔧 Troubleshooting

### Common Issues

**Login Problems:**
- Ensure you have the correct Discord User ID and Server ID
- Check that you're a member of the Discord server
- Clear browser cache and try again

**Points Not Updating:**
- Points update automatically from Discord and Twitch activity
- Check the leaderboard page for current standings
- Contact server administrators if issues persist

**Calendar Not Loading:**
- Refresh the page or clear browser cache
- Ensure you have proper permissions in the Discord server
- Check server status on the diagnostics page

### Getting Help
1. Check the diagnostics page in settings for system status
2. Contact your server administrators
3. Join the Space Mountain Community for support

## 📊 System Status

Visit the **Settings > Diagnostics** page to check:
- System health and uptime
- API connectivity status
- Recent error logs
- Performance metrics
